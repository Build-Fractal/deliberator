### Final Position Statement

**Non-Negotiables**

1. The supplemental blind deliberation with a contrarian agent must run before any new attestation of spec 070 §9 AC #5 satisfaction. The contrarian agent prompt must explicitly argue that one or more of VI, X, or XVI passes the v2.4.0 gate and should NOT be migrated; the deliberation must run against a pre-cycle-1 document that still contains all three principles. Without this test, the constitutional precedent for migrate-out rests on deliberations not configured to test their own central conclusion. This is the primary structural defect in the current closure state, corroborated by both GD and IP in their Phase 3 revisions (gap-detector/revision.md Rec 1; implementation-pragmatist/revision.md Rec 3 modified).

2. Spec 070's `specs/done/` placement must be corrected — through strict reopening or a named follow-up spec with explicit §9 AC #5 gap declaration — before the supplemental deliberation is treated as complete. The follow-up spec path is acceptable only if it meets all three conditions from gap-detector/revision.md Rec 2: explicit naming of §9 AC #5 as unsatisfied at PR #99 closure, its own spec 067 verification trail tied to the contrarian deliberation, and active `specs/` directory placement. A follow-up spec that does not explicitly name the §9 AC #5 gap does not correct the false certification; it papers over it with new content.

**Flexibility**

1. The named follow-up spec format vs. strict reopening. I am willing to accept the follow-up spec path as an operationally equivalent alternative to moving spec 070 back to `specs/`, provided the three conditions are met. What must be preserved: the historical record cannot claim §9 AC #5 was satisfied before the supplemental deliberation runs; the follow-up spec's active placement in `specs/` must signal process incompleteness to future readers. What I am flexible on: the specific form of the corrective vehicle (reopened spec vs. follow-up spec) is a governance-process detail that the synthesizer is better positioned to judge than the deliberating agents.

2. Sequencing of §4.1(c) examples relative to supplemental blind deliberation. I prefer the examples be added after the supplemental blind deliberation resolves the VI migration question, but I am willing to accept conditional parallel-track addition (examples added with an explicit documented review obligation if the deliberation outcome changes) if the synthesis determines audit-faithfulness's parallel-track framing is more operationally practical. What must be preserved: the logical dependency between the examples' authority and the migration's validity must be recorded somewhere in the change record — whether in CONTRIBUTING.md text, the PR description, or the synthesis itself — so the reversal path is not silently assumed away by future contributors encountering the examples without knowing their provisional status.

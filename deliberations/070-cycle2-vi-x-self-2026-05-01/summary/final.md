### Systemic Contradictions

- **Analytical scope asymmetry producing false consensus signals**
  - **Manifests in**: Disputes 3 and 4 (criterion classification, comparative asymmetry) — both contested only by rrs with scope exclusions from crc and ms; the "safe agreements" sections in cross-review documents where merits-based agreement could not be distinguished from silence; ms's cross-review of rrs noting "the arbiter should treat ms's silence on criterion classification as scope exclusion, not validation."
  - **Root cause**: The three agents naturally divided into one analytically-focused agent (rrs, scrutinizing decision process validity) and two execution-focused agents (crc scrutinizing navigational coherence; ms scrutinizing migration fidelity). No mandate required overlapping coverage of analytical dimensions. When a finding is raised by only one agent and others respond with scope exclusions, the deliberation record contains the finding but no adversarial pressure on it — creating apparent consensus through silence rather than through contested evaluation.
  - **Implication for spec**: The spec's amendment process should require that analytical validity dimensions (criterion identification, substrate analysis, comparative-principles consistency) are reviewed by at least two agents. The current three-agent assignment may systematically under-scrutinize analytical dimensions when one agent specializes there and the others concentrate elsewhere.

- **Conditional recommendation cascade creating implementation uncertainty**
  - **Manifests in**: crc-r3 and crc-r4 (conditional on VI's analytical validity); ms-r2 and ms-r3 (conditional on migrate-out standing for X); rrs-new (sequencing dependency framing); the Sequencing dispute. Collectively, six of the twenty-six recommendations cannot be implemented until the P1 substrate analysis (rrs-r2) is resolved.
  - **Root cause**: The migrate-out decision's analytical validity was not confirmed before the amendment was submitted. The P1 substrate analysis requirement (rrs-r2) functions as a hidden prerequisite that was not articulated until Phase 1 review. Without it, five P2–P3 recommendations appropriately hedge their implementation conditions, but the hedge creates a dependency cascade that the amendment's atomic commit requirement cannot fully capture.
  - **Implication for spec**: The amendment process should require documented substrate analysis before the migrate-out pattern can be invoked. If the v2.6.0 path (c) amendment established that substrate analysis determines WHICH path to use, the v3.0.0 migrate-out amendment should have demonstrated why no substrate existed, not deferred this demonstration to deliberation reviewers.

- **SIR narrative completeness vs. body text coherence gap**
  - **Manifests in**: The L1589 false assurance (SIR claims "zero body-text cross-references" while L1589 is a live body-text reference); the Criterion 1/Criterion 2 conflation (SIR narrative uses Criterion 2 description while labeling it Criterion 1); the audit methodology gap (plural forms not searched).
  - **Root cause**: The amendment's SIR was written as the comprehensive analytical document, while the Governance body text was treated as complete once the two principles were removed. The L1589 reference was in a paragraph added in v2.6.0 that explicitly pointed to VI and X as "future remediation" targets — precisely the paragraph that needed updating. The SIR's audit verification was performed on the principle bodies (where it correctly found no references) but was not extended to the Governance meta-commentary section, which discusses principles at one remove from the constitution's normative content.
  - **Implication for spec**: The cross-reference audit specification should explicitly include the Governance section (meta-commentary, path definitions, canonical precedent paragraphs) in its search scope, not only surviving principle bodies. Governance meta-commentary is the highest-risk location for stale references because it specifically discusses principles and amendment patterns by name.

- **Durable body text vs. concrete navigability tension**
  - **Manifests in**: L1589 wording dispute (ms wants specific names; crc/rrs want version/cycle); Governance destinations list (crc Rec 3 conditioned on analytical validity before naming CONTRIBUTING.md); migration pointer (crc Rec 4 conditioned on both removals being sustained).
  - **Root cause**: Constitutional body text serves two competing purposes simultaneously: it must be navigable enough that readers can locate entities without reading SIR comment blocks, and it must be durable enough that its factual claims remain true as the amendment record accumulates. Naming specific principles in the body text maximizes navigability at the cost of durability; naming only version/cycle references maximizes durability at the cost of navigability. The spec does not establish a convention for resolving this tension.
  - **Implication for spec**: A convention should be established: when constitutional body text refers to a completed amendment, use the version/cycle reference as the primary identifier, with principle names added only once all outcomes are final. This matches the canonical practice for legal citations (reference to the ruling, not to the parties, when outcomes may vary) and prevents the pattern where body text names entities that may change status before ratification.

- **Migrate-out precedent's analytical grounding as hidden critical path**
  - **Manifests in**: rrs-r2 (substrate analysis required before migrate-out is established as precedent); rrs-r3 (criterion classification error in SIR rationale); crc-r3, crc-r4 (conditional on analytical validity); ms-r2, ms-r3 (conditional on migrate-out standing); rrs-r6 (comparative asymmetry must be documented to prevent precedent extension).
  - **Root cause**: The migrate-out pattern is being established as constitutional precedent for the first time. Unlike path (c), which was established with explicit substrate analysis documentation (stage-3 Criterion 3 formal record in v2.6.0 SIR), the migrate-out precedent in v3.0.0 does not contain an equivalent analytical record demonstrating why path (c) was inapplicable — only an assertion that "no such substrate exists." Every downstream recommendation that depends on the migrate-out decision being sound is therefore conditionally valid. The constitutional record will be more durable if the migrate-out pattern is established with the same analytical rigor that path (c) was.
  - **Implication for spec**: Future migrate-out amendments should include a documented substrate analysis equivalent to the Criterion 3 formal record used for path (c) decisions. The analytical obligation is symmetric: just as path (c) required documenting that parameter pinning WAS a qualifying substrate, migrate-out requires documenting that no qualifying substrate EXISTS. The SIR should contain this demonstration, not merely assert the conclusion.

### Remaining Disputes

- **Dispute: L1589 Replacement Wording — Specific Principle Names vs. Version/Cycle Reference**
  - **Positions**: ms (disputes.md, Dispute 1) proposes naming "Principles VI and X" explicitly in the migrate-out clause: "Principles VI and X were subsequently remediated via the migrate-out pattern in this (v3.0.0) amendment." crc (disputes.md, Dispute 1) and rrs (revision.md, Rec 1 Modified) propose using version and cycle only: "Grandfathered-principle remediation electing the migrate-out pattern is governed by the v3.0.0 MAJOR amendment (spec 070 cycle 2) as the canonical migrate-out precedent."
  - **Arguments**: ms argues that naming VI and X provides the most navigable and auditable form — future amendment authors immediately know which principles are covered without cross-indexing. ms further argues that the robustness advantage of the conservative text is illusory: if X is retained via path (c), the MAJOR classification itself changes (losing X's removal), so "v3.0.0 MAJOR amendment (spec 070 cycle 2)" would also describe a different amendment — neither text version survives X's retention intact. crc and rrs argue that naming VI and X encodes an outcome that remains analytically contested (the substrate analysis for X is a P1 pre-ratification requirement). If the substrate analysis concludes X warrants reconstitution, the body-text sentence naming X as a migrate-out example would be constitutionally false. The conservative text survives any downstream outcome. crc proposes that once X's disposition is finalized, a subsequent PATCH can name the principles explicitly.
  - **Synthesizer assessment**: crc/rrs's position is stronger. ms's counter-argument — that if X is retained the version/cycle reference is also wrong — conflates the amendment's identity with its outcome encoding. "Spec 070 cycle 2, v3.0.0" identifies the amendment event without encoding what the amendment did to X; "Principles VI and X were remediated via migrate-out" encodes the outcome directly. If X's status changes, the version/cycle reference still correctly points to the amendment where the migrate-out pattern was first established (even if X ultimately was not removed in that amendment — the pattern was still introduced there). Furthermore, the conservative text is a staging measure: its correctness costs nothing because the version/cycle reference is sufficiently concrete for navigation, and naming principles in a PATCH once status is final is trivially low-cost. The risk asymmetry is significant: a wrong principal-name in constitutional body text requires a corrective amendment; a version/cycle reference that could have been more specific requires only a PATCH clarification. Given that the substrate analysis for X is a co-equal P1 pre-ratification requirement, the conservative text is the appropriate form for the initial ratification.
  - **Recommended resolution**: Adopt crc/rrs's formulation. The full L1589 replacement text is: "The 2026-05-01 spec 070 cycle 1 amendment establishing this definition is the canonical path (c) precedent for grandfathered-principle remediation that elects to retain a principle in the constitution with a restructured headline (see Principle XVI). Grandfathered-principle remediation electing the migrate-out pattern is governed by the v3.0.0 MAJOR amendment (spec 070 cycle 2) as the canonical migrate-out precedent."

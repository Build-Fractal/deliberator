### Dangerous Contradictions

- **Version classification: PATCH vs. MINOR**
  - **cross-principle-coherence claims**: The review accepts the 2.6.0 (MINOR) classification without challenge. Its recommendations treat the amendment as a legitimate MINOR expansion and propose governance text to legitimize "headline rewrites" — implicitly accepting that this class of amendment warrants a MINOR bump. (cross-principle-coherence, Recommendation 2: "Headline rewrites of grandfathered principles that restructure existing body content into a new headline without introducing new normative requirements are treated as wording-level amendments.")
  - **gate-skeptic claims**: The SIR's own language — "the structural substrate already living in XVI's body IS mechanically verifiable" — identifies the rewrite as reorganization of existing content. Reorganization-without-new-content is PATCH by the constitution's definition. Miscategorizing it as MINOR signals that editorial reorganization of body content counts as material expansion. (gate-skeptic, Recommendation 3: "The SIR states the substrate 'already lived in XVI's body.' If the content already existed, the version bump is wrong.")
  - **Why this is dangerous**: If cross-principle-coherence's Recommendation 2 is adopted (governance definition of "path (c)"), it should specify that path (c) amendments are PATCH, not MINOR. If it instead legitimizes the MINOR classification, it sets a precedent that content-reorganization-without-addition constitutes material expansion — and the next amendment that promotes existing body sentences to headline status will claim the same MINOR bump without genuinely expanding the constitution. The two positions create incompatible precedents for the same class of amendment.
  - **Suggested resolution**: gate-skeptic's version-classification argument is the load-bearing one here. Cross-principle-coherence's Recommendation 2 should be revised to explicitly state that path (c) amendments are PATCH unless they introduce new normative requirements not present in the prior body — which is exactly the framing gate-skeptic's Recommendation 3b proposes. Cross-principle-coherence should yield on this point; the governance definition it proposes is only useful if it binds the version classification correctly.

- **Primary diagnosis of the plain-language pairing failure**
  - **cross-principle-coherence claims**: The plain-language requirement is substantively valid and passes Criterion 2 on its face. The primary problem is that the enforcement mode is unspecified relative to XV: "If a plugin emits numerical output without plain-language pairing, is the violation (a) a schema-level rejection blocking plugin output, (b) a parser-level failure triggering XV's warn-and-continue, or (c) silently ignored?" Fix: add one sentence specifying that violations trigger XV's warn-and-continue. (cross-principle-coherence, Missed Opportunities: "Enforcement mode for plain-language MUST is unspecified"; Recommendation 1.)
  - **gate-skeptic claims**: The plain-language requirement fails Criterion 2 because "plain-language" has no structural definition. The body's example ("87% of agents are at their best possible position given others' positions") is one compliant instance, not a definition of the boundary. A reviewer encountering "Equilibrium quality: 0.87 (a measure of agent satisfaction)" must interpret whether that passes. Criterion 2 requires that a reviewer can flag a violating PR without interpretation. Fix: add a structural definition — string-typed field, does not repeat the numerical value, expresses meaning in domain terms. (gate-skeptic, Recommendation 4.)
  - **Why this is dangerous**: The two fixes address different layers and do not substitute for each other. Cross-principle-coherence's fix (enforcement mode sentence) leaves Criterion 2 unresolved — the principle still cannot flag a borderline violating PR without reviewer judgment. Gate-skeptic's fix (structural definition) leaves the XV enforcement conflict unresolved — a compliant explanation field in a plugin recommendation still has undefined violation consequences. If only one fix is applied, the amendment either remains ratifiable-but-operationally-ambiguous (cross-principle-coherence's fix only) or becomes more precise but still XV-conflicted (gate-skeptic's fix only). Both fixes must ship together, but neither review identifies the joint dependency explicitly.
  - **Suggested resolution**: Adopt both fixes in sequence. First, add gate-skeptic's structural definition to the principle body (Criterion 2 fix). Second, add cross-principle-coherence's enforcement mode sentence anchoring violations to XV's warn-and-continue (XV conflict fix). The structural definition provides the predicate that the enforcement mode sentence acts on — the order matters. Neither review should treat its fix as sufficient alone.
